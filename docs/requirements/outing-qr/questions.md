### Q-01: What happens when a member scans the QR code
- **Question:** When a member scans the outing's QR code with their phone, what should they see?
- **Why it matters:** It decides whether the QR is only a shortcut to the existing outing page or whether it changes the voting flow. Today a person must first tap "Đi" (Going) and only then can vote; skipping that step would change an existing rule.
- **Related:** FR-02, FR-04, AMB-01, A-03
- **Options:**
  - A) The normal outing page, exactly as when opening the link from chat; the member taps "Đi" and then votes as today.
  - B) The same outing page, but scrolled / jumped straight to the "Đi / Không đi" and vote part.
  - C) The member is marked "Đi" (Going) automatically by scanning and only has to choose a venue.
  - D) Other (please describe)
- **Answer (original):** A
- **Answer (English):** A (The normal outing page, exactly as when opening the link from chat; the member taps "Đi" and then votes as today.) [answered 2026-10-16 via a form listing the options; free-text notes field left as "—"]
- **Status:** confirmed
- **BA note:** Confirmed 2026-10-16. Applied to FR-02 and FR-04: scanning opens the normal outing page, exactly like the chat link; the member taps "Đi" and votes as today. AMB-01 resolved (reading a); A-03 confirmed.

### Q-02: Who can show the QR code
- **Question:** Who can open the outing's QR code to show it to others?
- **Why it matters:** It decides whether the QR is an organizer-only tool (like closing early) or something every member can use to bring in more colleagues.
- **Related:** FR-05, G-01
- **Options:**
  - A) Anyone who opens the outing (any member can show the QR to colleagues).
  - B) Only the organizer (chủ kèo), from the browser that created the outing, like the other organizer actions.
  - C) Other (please describe)
- **Answer (original):** A
- **Answer (English):** A (Anyone who opens the outing (any member can show the QR to colleagues).) [answered 2026-10-16 via a form listing the options; free-text notes field left as "—"]
- **Status:** confirmed
- **BA note:** Confirmed 2026-10-16. Applied to FR-05: the QR code is shown to anyone who opens the outing; it is not an organizer-only action. G-01 resolved.

### Q-03: Where and how the QR code is shown
- **Question:** Where should the QR code appear on the screen?
- **Why it matters:** A small code always visible on the outing page makes the page longer on a phone; a large code on demand is easier to scan from a distance. This shapes the screen design.
- **Related:** FR-06, G-02, AMB-02
- **Options:**
  - A) Always visible on the outing page, below the outing details.
  - B) A "Hiện mã QR" (Show QR code) button on the outing page that shows the code large, filling the screen, with a way back to the outing.
  - C) A separate QR page for the outing (its own address), reached by a link on the outing page.
  - D) Other (please describe)
- **Answer (original):** A
- **Answer (English):** A (Always visible on the outing page, below the outing details.) [answered 2026-10-16 via a form listing the options; free-text notes field left as "—"]
- **Status:** confirmed
- **BA note:** Confirmed 2026-10-16. Applied to FR-06: the QR code is always visible on the outing page, below the outing details; no button, no separate page. G-02 resolved. Because the outing details are already above the code, Q-07 was refined to ask only what goes next to the code.

### Q-04: Which outings offer a QR code
- **Question:** For which outings should the QR code be offered?
- **Why it matters:** After an outing closes nobody can vote any more, so a QR "to vote" may be confusing there; but it could still be useful for people to see the result.
- **Related:** FR-07, G-03
- **Options:**
  - A) Only open outings (where people can still answer and vote).
  - B) All outings, including closed, waiting for the organizer's choice and cancelled ones (scanning then shows the result page).
  - C) Other (please describe)
- **Answer (original):** A
- **Answer (English):** A (Only open outings (where people can still answer and vote).) [answered 2026-10-16 via a form listing the options; free-text notes field left as "—"]
- **Status:** confirmed
- **BA note:** Confirmed 2026-10-16. Applied to FR-07 and BR-04: the QR code is shown only while the outing is open; closed, waiting-for-the-organizer and cancelled outing pages do not show it. G-03 resolved. Consequence recorded as A-07 (an earlier screenshot of the code still opens the outing page in its current state).

### Q-05: Saving or sharing the QR code as an image
- **Question:** Besides showing the QR code on screen, should people be able to save it as an image (for example to post it in the chat or print it)?
- **Why it matters:** Saving / downloading is extra work; if the QR is only for scanning in person, it is not needed.
- **Related:** FR-09, G-04, AMB-02
- **Options:**
  - A) No, showing it on screen is enough (people can still take a screenshot).
  - B) Yes, a "Tải mã QR" (Download QR code) button that saves it as an image.
  - C) Other (please describe)
- **Answer (original):** A
- **Answer (English):** A (No, showing it on screen is enough (people can still take a screenshot).) [answered 2026-10-16 via a form listing the options; free-text notes field left as "—"]
- **Status:** confirmed
- **BA note:** Confirmed 2026-10-16. Applied to FR-09 and scope out: no download button; showing on screen is enough (screenshots remain possible). G-04 resolved; AMB-02 resolved (reading a).

### Q-07: What is shown next to the QR code
- **Question:** The QR code will sit on the outing page, below the outing details (date, sitting time, close time). What should be shown together with the code itself?
- **Why it matters:** A short caption tells people what the code is for; the link as text with a copy button helps someone who cannot scan, but makes the page longer on a phone. (Refined after Q-03 = A: the outing's date and time are already shown above the code, so they are no longer an option here.)
- **Related:** FR-08, G-06
- **Options:**
  - A) Only the QR code, nothing else.
  - B) The QR code with a short caption, for example "Quét mã để vào kèo" (Scan the code to join the outing).
  - C) The caption of B, plus the outing link as text with a "Sao chép link" (Copy link) button.
  - D) Other (please describe)
- **Answer (original):** A
- **Answer (English):** A (Only the QR code, nothing else.) [answered 2026-10-16 via a form listing the options; free-text notes field left as "—"]
- **Status:** confirmed
- **BA note:** Refined 2026-10-16 after Q-03 = A. Confirmed 2026-10-16. Applied to FR-08 and scope out: only the QR code itself is shown, with no caption, no link text and no "Sao chép link" (Copy link) button. G-06 resolved.
